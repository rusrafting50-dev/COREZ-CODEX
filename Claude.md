# СЧИТАЛКА

## Назначение

Веб-приложение для автоматизации проведения всероссийских
соревнований по рафтингу. Замена Excel-файла СЧИТАЛКА.xls.

## Стек

* Backend: Python, Flask
* Frontend: HTML, Bootstrap 5, JavaScript
* База данных: SQLite (файл local.db)
* Язык интерфейса: русский

## Классы судов

* R4: экипаж  4-5 человек
* R6: экипаж 6-7 человек
* Все команды представляют субъект РФ и участвуют в командном зачёте

## Дистанции (в порядке проведения)

1. СПРИНТ — линейная гонка, результат = время + штраф
2. ПАРАЛЛЕЛЬНЫЙ СПРИНТ — турнирная сетка, старт от места в спринте
3. СЛАЛОМ — 2 попытки, считается лучшая, ворота со штрафами 5/50 сек
4. ДЛИННАЯ ГОНКА — линейная, результат = время + штраф
5. МНОГОБОРЬЕ — сумма очков за места на всех дистанциях
6. ЗАЧЁТ СУБЪЕКТОВ — командный зачёт по таблице коэффициентов

## Логика расчёта результата

* Время прохождения = время финиша − время старта
* Результат = время прохождения + штрафное время
* Штрафное время = количество штрафов × значение (5 или 50 сек)
* Дисквалификация и "последнее место" — отдельные статусы

## Параллельный спринт — особая логика

* Турнирная сетка зависит от числа команд (3-16)
* Стадии: 1 этап → 1/16 → 1/8 → 1/4 → 1/2 → Финал А/Б
* Победитель заезда: меньший штраф; при равенстве — лучшее время
* Посев в сетку — по результатам спринта

## Документы системы

### Предварительные

* Техническая заявка (по делегациям)
* Выписка из протокола комиссии по допуску
* Акт технической комиссии
* Протокол жеребьёвки
* Протокол выдачи нагрудных номеров
* Акты утверждения дистанций (СП, ПП, СЛ, ДГ)
* Справка о судейской коллегии
* Справка о субъектах

### По каждой дистанции

* Предварительный протокол (стартовый)
* Протокол финиша (ввод времён и штрафов)
* Протокол результатов (итоговый)

### Итоговые

* Протокол многоборья
* Комплексный зачёт субъектов
* Отчёт ФРР
* Отчёт ФЦПСР

## Таблицы очков (из файла)

* Спринт: 1м=100, 2м=95, 3м=90 ... (шаг 5)
* Параллельный спринт: 1м=200, 2м=190 ... (шаг 10)
* Слалом: 1м=300, 2м=285 ... (шаг 15)
* Длинная гонка: 1м=400, 2м=380 ... (шаг 20)
* Многоборье: 1м=400, 2м=380 ... (шаг 20)

## Справочники

* Разряды: таблицы Разряды\_С, Разряды\_Д, Разряды\_М
* Штрафы: таблицы по каждой дистанции (Штрафы\_старт, финиш, ПС, СЛ, ДГ)
* Очки субъектов: таблица с коэффициентами зависящими от числа субъектов

## Структура файлов проекта

* app.py — главный Flask сервер
* models.py — модели базы данных
* routes/ — маршруты по разделам
* templates/ — HTML шаблоны
* static/ — CSS, JS
* local.db — база данных SQLite
* СЧИТАЛКА.xls — исходный файл (только для справки)

## Требования к интерфейсу

* Все протоколы доступны для редактирования
* Изменения сохраняются в БД
* Каждый протокол можно распечатать (print CSS)
* Навигация по дистанциям и этапам

## Технические ограничения

* Кириллица в параметрах URL недопустима — только латиница
* Set-Content всегда с -Encoding UTF8
* SQLAlchemy должен быть последней версии (pip install --upgrade)
